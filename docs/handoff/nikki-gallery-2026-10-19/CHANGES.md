# 本机当前实现与近期变化

## 照片预览与界面

- 修复滑动松手时旧图片过早移除造成的闪黑；交接动画期间两张图片保持一个页面宽度的距离，未加载邻图不提交为空白页。
- 分享图预览接入既有玻璃界面和预测性返回，操作为“保存分享图”“保存原图+分享图”“关闭”；保存/分享进度和 LIVE 保存选项沿用同一套界面组件。
- UID/昵称支持默认档案。分享图保留可配置昵称、UID、水印文案；普通 EXIF 不再使用昵称作为相机名称。

## LIVE

- 原图库及已保存的完整 LIVE 支持打开后自动静音循环播放，有暂停、声音开关；切换照片、缩放、详情、返回和后台时暂停或释放，首帧到达前保留封面。
- 预览使用 Media3 1.8.0 / TextureView，只播放已认证下载并校验后的本地副本。私有预览缓存额度256MiB，单份源128MiB；超限或失败保留封面及原有保存路径。
- 修复游戏 MP4 合法容器后附带完整参数封套时，vivo 导出误报“MP4 box长度无效”。仅在合法边界识别完整已知封套，将其保留进导出副本的有限 free box，再附加厂商关联信息；不重编码，不修改游戏源文件。
- 各手机原生相册的 LIVE 识别仍依赖系统和相册版本；容器校验成功不等于所有机型验收。关联修图和小组件仍显示静态图片。

## 已保存、EXIF、关联修图和小组件

- 已保存详情使用真实本地 URI 解码，读取方向信息并采样高分辨率图片；缩略图继续服务列表，避免用低清列表图替代详情。
- 原图及兼容修图副本的相机字段固定为 Make=`MomoCamera`、Model=`MomoCamera,Infinity Nikki`、Software=`MomoCamera`。LensMake 为照片所属游戏版本的英文名称，例如2.9 `Bloom Beneath Bright Skies`、2.10 `The Feather of Justice`；未知标题留空。
- 关联修图保留源 assetId、已保存 URI 与拍摄/搭配参数快照；对支持的 JPEG/PNG/WebP 创建并校验 EXIF 副本，不覆盖用户选择的修图。HEIC/AVIF 不宣称已经写入 EXIF。
- 小组件移除手动切图按钮，按系统周期轮换；宽组件排除考虑方向后的竖图，保持等比展示。既有低清导出文件无法凭空恢复，需要重新保存原图。

## 元数据补全和版本

- NUAN5 与 NikkiGallery 的同照片结果统一到 camera、pose、filter、lighting、dressing、photography、nikki、interactions 等结构；已有值优先，只补缺失字段，数组成员按精确 ID 合并。
- 服装、动作、滤镜、光照名称从公共字典按精确 ID 补全；缓存参数可离线升级标准字段，不重复提交已有解码结果。没有取得的动作、光照或滤镜不能猜测为已解码。
- 游戏版本推测新增2.10并支持公开官网检查和缓存；英文版本名另取公开官方公告。在线检查失败保留本地结果，明确版本优先，只有日期而无开服时间的边界不伪造小时。
- 日历、英文名或可见参数变化时更新相关照片 revision，通过已有变更日志/事件刷新手机；不修改源照片和原生参数。
- 在线参数解析默认开启，可在电脑同步设置关闭，已有明确关闭选择会保留。开启时第三方接收游戏 UID、编码参数与校验值；公共字典/版本查询和照片局域网传输属于不同路径。

## 连接恢复和电脑更新

- Android 发现兼容带/不带尾点的服务类型；串行解析、失败重试、忽略旧网络回调。返回前台恢复连接，首次图库读取失败后重新补载。
- 实时通道空闲15秒发送 masked ping，继续无响应则重连；认证失败和证书改变分别提示，不放宽安全校验。
- EXE 每15秒检查 mDNS 所用地址，切换热点/Wi-Fi 后重建广播，保留忽略自身响应的保护，避免组播反馈循环。
- 生产 HTTPS WebSocket 的回归证实旧 Bun 1.3.14 握手写入未送达；切换1.4.1 baseline，仍兼容不支持AVX2的CPU。构建脚本拒绝旧运行时，CI 加入实际 Bun TLS 握手测试。
- 左侧“关于”集中显示版本、仓库和检查更新，手机也包含 NikkiGallery 仓库链接；两端加入百度网盘下载入口。
- EXE 的一键更新校验 RSA 签名清单、完整文件大小和 SHA256，下载完整 EXE 后重启替换，并保留旧文件用于失败回滚；不是增量补丁。配对、设置、索引存放在用户数据目录，不随 EXE 替换删除。
