大喵相机助手 1.0.15 公测版

本包包含电脑端 EXE、安卓 APK、使用说明和文件校验值。
电脑端也内置相同版本的 APK，可从首页“首次使用引导 → 导出安卓安装包”保存。

开始使用：
1. 从电脑右下角托盘退出旧助手，再打开 MomoCamera-PC-1.0.15.exe。不要删除旧助手的数据目录。
2. 手机安装 MomoCamera-Android-1.0.15.apk。近期公测版可直接覆盖安装，保留已有数据；不要先卸载。若提示签名冲突，请保留原 App，反馈情况后再处理。
3. 电脑和手机连接同一 Wi-Fi，或让电脑连接运行 App 的手机热点。首次使用时用 App 扫电脑端配对码；已配对设备正常情况下会自动重连。

首页引导的快捷入口：
- 导出安卓安装包：把 APK 发到手机安装。电脑端已经内置，不用另找下载地址。
- 打开同步设置 · 连接排障：扫码后超时、显示电脑不可达时，进入“本地网络权限”，点击“允许手机连接”，在 Windows 弹窗中选择“是”。这是可选排障，已经能连接时无需操作。
- 添加扫描目录 · 查看选目录说明：进入额外扫描目录并展开说明，选择实际保存照片的文件夹，核对预览后确认加入共享相册。不会自动把选中的目录直接分享。

如何选目录：
- 默认游戏相册继续自动扫描；只有照片没出现、相册搬迁或使用外部截图软件时才需额外添加。
- 旋转吧大喵：先在该软件“设置 → 输出目录”查看实际位置。默认通常为系统“视频”下的 SpinningMomo；以你的软件设置为准。
- 搬迁的游戏相册：推荐 GamePlayPhotos 或其中的 UID 文件夹。保留原图、缩略图和 LIVE 的完整结构。
- 静态原图：选择 NikkiPhotos_HighQuality。不要选择 NikkiPhotos_LowQuality，它是缩略图。
- 普通截图或修图导出：选择实际保存 JPG/JPEG、PNG、WebP 的文件夹。包含子文件夹，不要选择整个磁盘。

确认后目录会加入本机共享相册，所有已配对设备均可访问。最多16个目录，重启后保留；移除只停止扫描和分享，不删除电脑原文件或手机已保存照片。
普通截图可能没有游戏拍摄参数；普通 MP4 不会自动成为 LIVE。PNG/WebP 可原样保存，手机旋转保存目前请使用 JPEG。

连接仍失败：
校园网、公司和公共 Wi-Fi 可能隔离设备，网络授权不能解除路由器隔离。可优先试手机热点；仍失败时导出连接诊断报告并反馈。
网络授权仅允许本地子网访问当前后台服务的同步 TCP 端口，可在同步设置撤销；不会关闭 Windows 防火墙。
