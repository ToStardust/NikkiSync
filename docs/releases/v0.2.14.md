# NikkiSync 0.2.14 测试版

本版修正 Android Oplus LIVE 的封面时间戳和媒体布局。一加 Ace 2V 测试者此前反馈“原视频正常、LIVE 卡顿”；更新后用户转述该测试者反馈“LIVE 不会卡了”。已知环境为用户提供的系统 `16.0.5`、相册 `16.50.8`，该案例保存前未旋转。

这是一台设备的一次流畅度回归反馈；清晰度改善、音轨、重启、非零旋转和其他机型未取得本次验证结果。系统完整构建号、相册包名及版本码也未提供。不按这条记录推断全部一加/OPPO/realme 机型通过。

## 下载与使用

- **Windows 用户下载 `NikkiSync-PC.exe` 即可**：单文件绿色程序，已内嵌本版 Android APK 和运行组件。打开后按电脑页提示连接手机；优先自动检测游戏目录，无需先开游戏。首次展开后复用本机运行环境。
- `NikkiSync-Android.apk` 是同一版本的独立 Android 安装包，要求 Android 13 或以上。已有旧版可覆盖安装，保留配对和缓存。
- 若只有手机需要更新，可以只下载 APK，电脑端不必同步替换。
- 旧 LIVE 文件不会自动更新；要使用新的封装，需要在 NikkiSync **重新保存那张 LIVE**。
- `SHA256SUMS.txt` 列出 EXE 和 APK 的 SHA-256 校验值。

Windows 包面向 x64；WebView2 未安装时会在启动界面提供安装入口。小程序原生 LIVE 保存仍搁置，照片、原视频和分享图功能保持现状。

## 本版修改与验证

- Oplus 私有封面时间戳与实际封面 sample PTS 保持一致，媒体目录补齐零填充字段，完整 MP4 紧接 JPEG EOI。
- 未旋转的 LIVE 保留完整原始 MP4，不转码、不截短、不改分辨率或帧率；保留源文件、JPEG 压缩图像与独立参数快照。
- Android 完整单元回归 199 项、公共 LIVE 核心 108 项检查通过；APK v2 签名通过，与上一版使用同一证书。
- 实际交付 EXE 的内置 APK 已提取核对，哈希与独立 APK 一致。
