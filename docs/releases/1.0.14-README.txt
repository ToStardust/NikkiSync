大喵相机助手 1.0.14 公测版

项目仓库：https://github.com/ToStardust/NikkiSync
下载与后续版本：https://pan.baidu.com/s/5bb_o2A8iJ2MR4f_hRBlPCw

本包包含 Windows 电脑助手与 Android 手机 App，电脑端也内置同一份 1.0.14 APK。
支持 Windows 10/11 64 位和 Android 11 及以上系统。

使用方法
1. 电脑和手机连接能够互相访问的网络。可以连接同一路由器，也可以由运行 App 的手机开启热点，让电脑连接它。
2. 如旧电脑助手仍在运行，请从右下角托盘右键“退出”，再打开本包的 MomoCamera-PC-1.0.14.exe。仅关闭窗口会缩到托盘。
3. 手机覆盖安装 MomoCamera-Android-1.0.14.apk，打开 App。与近期公测版使用相同签名，保留已有配对、保存记录和设置。
4. 已配对用户先等待自动恢复；首次使用或旧地址无法恢复时，请扫描新电脑助手显示的二维码。
5. 电脑端关闭窗口后会继续在托盘运行。退出电脑助手后，远程照片连接暂停。

连接改进
手机会优先检查原地址，再自动尝试二维码或之前连接中记住的备用地址。只接受与配对证书和电脑身份一致的服务，成功后记住可用地址。
二维码、自动发现及网络切换继续兼容旧配对流程。建议电脑和手机同时更新到本包版本，以使用完整的多地址连接能力。
校园网若禁止设备互相访问，正确地址也可能无法直连；此时可换手机热点测试。本版不使用云端照片中继。

保存改进
保留华为、荣耀自动选择动态照片格式；合入三星普通照片和 LIVE 保存目录、最新日期显示的调整，以及大 LIVE 封装校验的内存保护。
三星新保存文件使用保存时间显示，原游戏拍摄时间仍保留在 App 记录和参数快照中。此前导出的照片不会自动迁移或修改。

反馈建议
连接失败时请注明电脑端、App 版本，以及使用家用 Wi-Fi、校园网还是手机热点。已有连接诊断工具的用户，可在本版电脑助手运行时重新生成报告。
LIVE 问题请注明手机型号、系统/相册版本、是否旋转、文件大小和完整提示。
