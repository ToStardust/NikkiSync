# 大喵相机助手 1.0.5 公测版

Windows 1.0.5 / build2026101805；Android 1.0.5 / code29。

这是公测版本。提供 Windows EXE、独立 Android APK、电脑＋手机统一 ZIP，以及用于电脑检查更新的签名清单。

同时修复首次从干净源码构建时的生成顺序；源码构建和回归测试通过后发布。此前的 beta.1 仅建立了源码标签，没有公开安装包。

## 本轮更新

- 电脑左侧新增“关于”，集中显示版本、作者、检查更新、本项目仓库与 NikkiGallery 仓库，移除正常界面右上角的更新栏。
- App“关于&更新”加入 NikkiGallery 仓库；该地址按维护者指定保留。
- 原图库和已保存的完整 LIVE 可在预览页自动静音循环播放，提供暂停及声音开关。滑动、缩放、详情、返回时回到封面，后台释放播放器；已保存 LIVE 支持离线读取。
- 修复 vivo 保存时有效游戏视频末尾参数被误当成 MP4 原子的问题；仅处理导出/播放副本，电脑原文件及拍摄、搭配参数保留。
- 改善已保存照片和小组件的清晰度，移除组件手动切图按钮，横向组件默认排除竖图。
- 普通 EXIF 相机名称使用 `MomoCamera,Infinity Nikki`；镜头厂商写入照片对应版本的英文名称。关联修图保留参数关系，并为支持的照片副本补写 EXIF。
- 电脑助手加入带签名和完整性检查的一键更新、启动失败恢复；更新保留配对、设置和图库数据。版本/名称日历可从公开来源检查更新，失败保留缓存。

## 使用方式

Windows 下载 `MomoCamera-PC-1.0.5.exe` 运行，内置同版 APK，可导出后在手机安装；也可直接下载独立 APK。电脑和手机按原方式连接到同一局域网并扫码配对。

本次公测 APK 使用新的匿名签名证书，无法直接覆盖此前使用旧签名的 Android 版本。请保留旧 App 和数据，不要为解决签名冲突直接卸载或清除数据；迁移前请通过项目仓库反馈。后续公测版将沿用新签名。Windows 更新仍保留原有数据。

已具备电脑一键更新功能的版本可在发布完成后检查到新版。首次使用或更早版本请下载完整 EXE。小程序不包含本次 Android 内置 LIVE 播放器改动。

动态预览使用应用私有缓存（256 MiB 额度，活动文件受保护），单份预览源上限 128 MiB。读取失败保留封面，可重试；超限仍可使用原有保存功能。清理动态缓存不删除系统相册照片或视频。
