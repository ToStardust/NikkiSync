# 大喵相机助手 1.0.40 公测更新

- 安卓照片详情恢复液态玻璃并提高文字对比度，精简 LIVE 格式下的测试说明。照片缺少参数时，根据可识别的照片类型或来源显示原因。
- 补充 21 张滤镜图标，App 和新版小程序分享图支持动作、光照及滤镜缩略图。
- 继续提供本地参数解码、本地部件图标、电脑程序更新，以及安卓「最近拍摄」分组和全选保存。
