大喵相机助手 1.0.22 公测版

电脑先从右下角托盘退出旧助手，再运行新版 EXE。
手机 APK 可直接覆盖安装相同公测签名的旧版，不要卸载或清除数据。
原有配对、设置、照片、缓存和整理记录保留。
已开启自启动的用户，首次打开新版会自动更新启动路径，无需重新切换开关；请将 EXE 放在准备长期保留的位置。若自行在 Windows 禁用了启动应用，请在系统设置中恢复。
本次主要更新电脑连接排障；手机已有 1.0.21 也可继续连接使用。

连接失败时
在电脑端二维码配对页面，点击“连接失败？导出诊断包”，选择保存位置。
等待提示保存完成，把生成的 ZIP 压缩包发给开发者，并补充手机型号、App版本、连接方式和手机端报错截图。
诊断包自动整理电脑连接检查、当前版本、修复结果及筛选后的启动日志，不包含照片、配对码、密钥或个人路径，不会自动上传。
个别检查未完成时仍会导出已收集的信息；检查本身不修改网络或防火墙。

修复连接权限
进入“同步设置 → 本地网络权限 → 一键检查并修复”，同意 Windows 提示后再用手机连接。
本版修复同名规则造成阻止项被跳过的问题；同名 UDP、其他程序和其他端口规则保留。
仍有歧义或受管理、附带复杂限制的规则会继续跳过。需要恢复时可撤销上次修复。

照片删除仍需电脑确认并保持手机连接，只移入 Windows 回收站，可从回收站恢复。
