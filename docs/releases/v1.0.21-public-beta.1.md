# 大喵相机助手 1.0.21 公测版

Windows 1.0.21 / build2026102308，Android 1.0.21 / versionCode45。包含自上一份 GitHub 公测版 1.0.15 以来的改进，EXE 内置 APK 与独立 APK 完全一致。

## 离线整理与最近删除

- 手机离线时可浏览已经缓存的照片缩略图，沿用在线预览界面，暂时禁用需要连接电脑的操作；离线顺序与相册顺序一致。
- 手机可标记待删除照片，在“已保存 → 最近删除”查看及取消；离线标记只保存整理记录，不直接删除电脑或手机文件。
- 电脑新增独立的“最近删除”相册网格和首页数量入口，可展开核对关联文件，也可一次全选确认。
- 删除流程：手机标记 → 电脑核对并确认 → 手机保持连接完成核对 → 移入 Windows 回收站。可从电脑回收站恢复，手机已保存副本不受影响。
- 优化整批目录匹配、后台处理和扫描事件合并，减少逐张重复扫描；保留文件内容校验、手机取消优先及回收站保护。
- 修复整批处理耗时导致后续确认过期、需要重复点击全选的问题；核对完成后再开放全选，处理过程显示进度，已完成照片不再占位。
- 真实长时间断线仍会暂停尚未开始的照片，重连后再确认；不自动绕过手机核对。

## 连接与相册扫描

- 本地网络权限窗口新增当前助手的防火墙冲突检查、有限范围修复和撤销，不关闭防火墙，不修改其他程序的规则；不能自动处理的规则会提示。
- 电脑 Android App 页面新增临时组网入口和使用说明，通过 Windows 移动热点让手机连接电脑。是否可用取决于电脑无线网卡和系统支持。
- 默认扫描补充 ScreenShot 中的拼图，并对原图与相同导出截图去重，减少手动添加 ScreenShot 后的重复照片。
- 添加搬迁相册目录时，额外检查附近的游戏原始相册，帮助找到穿搭和拍摄参数；未找到完整数据时在详情中简洁说明，不生成虚构参数。

## 界面与使用体验

- 已保存照片的穿搭详情复用预览页的部件图标；搜索页统一粉色背景，从常用穿搭进入搜索后返回原页面。
- 优化二维码和最近删除快捷入口、扫描目录说明、更新链接按钮、离线预览和多选刷新。
- 最近删除顶部控件统一液态玻璃样式，保存记录数量简写为“X张”。
