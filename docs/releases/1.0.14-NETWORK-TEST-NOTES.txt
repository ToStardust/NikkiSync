1.0.14 网络授权修复测试版 · 2026102107

修复 Windows 将“规则不存在”映射为文件未找到异常时，授权流程提前失败的问题。
启动时只读检查本工具规则，已添加的权限不再要求重复点击；将入口明确标为可选连接排障。
授权失败会显示具体阶段代码；已经能正常连接的用户无需操作此功能。

新增“手机连接 → 允许手机连接”：由用户点击后请求 Windows 管理员授权，为实际后台服务的同步 TCP 端口添加仅限本地子网的连接权限。
新增“同步设置 → 本地网络权限”撤销入口。
增加处理进度、取消、权限不足、服务校验失败和已授权提示；重复点击不会重复添加同一条规则。
授权只接受本 EXE 内置清单所验证的后台服务，不接收网页传入的路径或端口。
保持 1.0.14 的热点选址和备用地址重连，以及原有浏览、照片保存、LIVE 等功能。
内置安卓 APK 沿用已验证的 1.0.14，签名和字节未变。

此包用于远端热点连接验证；添加规则后仍需手机实际连接确认。
