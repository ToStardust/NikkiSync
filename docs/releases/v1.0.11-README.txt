大喵相机助手 1.0.11 公测版
Windows build 2026102102 / Android versionCode 35
2026-10-21

支持 Windows 64 位电脑与 Android 11 及以上手机（API 30+）。
HarmonyOS 等系统以实际 Android 兼容 API 为准，不能按厂商系统版本号换算。

首次使用
1. 解压后运行 MomoCamera-PC-1.0.11.exe。电脑需要已安装电脑版《无限暖暖》。
2. 手机安装 MomoCamera-Android-1.0.11.apk；电脑助手也可导出完全相同的 APK。
3. 手机与电脑连接到可互访的同一局域网，阅读手机隐私说明后选择是否同意。
4. 用手机 App 扫描电脑助手的配对二维码，等待图库同步。

大相册首次启动
程序也会扫描 GamePlayPhotos 中的历史账号原件。首次处理较大相册时，请保持助手运行，观察已检查文件数、累计读取量和索引阶段。
扫描持续有实际进展时会继续等待，不再到两分钟就强制终止；连续两分钟无进展仍会超时，后台启动总等待上限为三十分钟。
累计读取量包含校验步骤的重复读取，可能大于相册实际容量。无需删除照片、历史账号目录或应用数据。

覆盖更新
1. 已使用匿名公测签名的近期版本可直接覆盖安装 APK，保留配对、收藏和设置。
2. 如果提示签名冲突，请联系开发者确认，不要直接卸载或清空数据。
3. 退出托盘中的旧电脑助手，再运行新 EXE；应用数据仍使用原目录。
4. 手机无需为本次兼容适配授予全盘文件、定位或整个相册读取权限。
5. 已安装 Android 1.0.11 的用户只需更新电脑 EXE；手机 APK 与此前的 1.0.11 兼容包完全相同。
6. 电脑已在运行旧版时，仅覆盖 APK 不会更新电脑后台；请从托盘退出旧助手后运行新版，再生成新的配对码。

旧系统显示说明
Android 11 保留半透明玻璃面板、边框、渐变遮罩与页面交互，关闭系统不支持的实时背景模糊。
Android 12 及以上保留 GPU 背景模糊。
修图选择器在旧系统上使用系统文件选择器，Android 13 及以上优先使用系统照片选择器。

测试范围
随包说明列出自动化回归结果。模拟器/单元测试不能替代华为、vivo 等厂商真机和相册的实际验收。
LIVE 的相册动态识别、硬件视频旋转能力以及局域网互访情况仍以实际设备为准。
电脑若仍启动失败，请在再次重试前通过“打开日志文件夹”反馈 startup-diagnostics.log、game-discovery.log、startup-timings.json 和 startup-service-timings.json。
只需这些启动日志，不要发送整个数据目录、数据库或照片。
