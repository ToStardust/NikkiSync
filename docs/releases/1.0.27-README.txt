大喵相机助手 1.0.27 公测版（抽屉优化版）

一、更新与启动
1. 电脑先从右下角托盘退出旧助手，再打开本包的 MomoCamera-PC-1.0.27.exe。
2. 手机安装 MomoCamera-Android-1.0.27.apk，直接覆盖旧公测版；不要卸载或清除数据。
3. 建议电脑和手机一起更新，以使用完整的账号同步、目录筛选和来源详情。
4. 原有照片、配对、已保存/修图关联及最近删除记录保留。

二、同步账号
电脑进入“同步设置 → 同步与连接 → 同步账号设置”，点击展开。
默认同步全部账号，包含以后发现的新账号。
如只需要几个账号，取消“同步全部账号”，根据 UID、照片数量和示例图勾选，再点击“保存同步账号”。
全部不勾选并保存，会暂不同步任何照片；未识别 UID 的照片有单独选项。
已添加的旋转吧大喵输出目录会单列“旋转吧大喵”，可以和 UID 账号分别勾选。
使用“选择旋转吧大喵输出目录”添加，或沿用默认 SpinningMomo 目录时会自动识别来源。旧版添加的自定义目录，可在“额外扫描目录”点击“标记为旋转吧大喵”；不会修改照片，也无需重新扫描。
这项设置影响此电脑向所有已配对手机共享的范围；不会删除电脑上的源照片。
手机完成同步后会移除被排除账号的图库列表和普通预览缓存。手机已保存照片与最近删除预览保留。
以后重新勾选该账号，手机会重新加载其图库并补充缓存。

三、缓存进度
App 首页“已同步 X 张 · 已缓存 Y 张”显示当前图库及可离线图片的缓存进度。
未手动设置容量时，小缩略图默认上限为 2GB；已手动选择的容量不会被覆盖。
在“我的 → 设置 → 缓存与离线整理”可调整上限，也可点击“继续 / 重试缓存（保持亮屏）”。
首次传输请保持电脑助手运行，手机 App 在前台，等待显示“已就绪”。后台或手动锁屏仍会暂停，返回后继续。
首次升级可能完整核对一次图库列表，未变化的已有图片仍会复用；不必一直滑动照片。
缩略图、高清预览和图片运行内存是不同的上限，2GB 是磁盘缓存上限，不会预先占满运行内存。

四、筛选与详情
图库搜索与筛选并排显示，左侧搜索大胶囊、右侧筛选小胶囊；已保存仍从原筛选入口进入。
筛选从底部弹出，UID 和目录选项直接在同一抽屉内展开，不进入二级页面。底部“应用”始终保留；取消或返回不提交选择。
目录显示易识别的名称与末尾路径；同名目录会补充足够的上级目录来区分，长文字换行、选项之间保留间距。
两处均可按照片类型、UID 和源文件夹筛选，点击“应用”生效；“全部”可解除对应条件。
目录选择页点击路径可展开完整位置，长按路径可复制。旧记录来源信息不完整时显示未知，连接新版电脑端后补充。
详情里的文件路径默认显示末尾文件名，点击可展开并复制完整电脑源路径；下方显示像素尺寸及文件大小。

五、游戏版本
已补充游戏 2.11 及英文名 Tales Woven in Time。
电脑启动及运行期间会定期检查官网与官方维护公告，缓存版本日历，连接后将变化同步到手机。
后续版本按官方信息自动跟进，不按固定天数猜版本；精确开服时间未核实时，过渡区间暂不强行归类。
无法联网时沿用已有日历；照片本身明确记录的版本优先。
