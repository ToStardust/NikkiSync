- 修复部分 LIVE 缺少对应视频时，误配其他照片视频、触发重复路径入库错误的问题。

## 后台恢复与诊断入口

- 电脑窗口底部固定提供“重启同步服务”和“导出诊断包”，切换页面、网页失效或启动失败时仍可使用，并显示实际运行版本与构建号。
- 服务不可用时收起旧二维码和“设备已配对”成功提示，避免把保留的配对记录误当作当前在线状态；重启后重新加载界面。
- 诊断包补充自身后台运行/退出状态、扫描目录与资源计数、具体数据库错误分类和失败步骤。不包含照片、数据库、个人路径、配对码或密钥，不自动上传。
- 反馈用户已确认恢复连接和照片访问；最初导致后台失效的具体外部原因仍未确认，恢复入口与诊断用于后续排查。
