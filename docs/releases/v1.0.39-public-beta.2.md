# 大喵相机助手 1.0.39 公测更新（beta.2）

电脑端和安卓 App 都更新为 1.0.39。电脑端是单文件 EXE，手机 APK 在 CNB 测试通道单独下载或在 App 内检查更新；覆盖安装同签名公测版会保留配对与本地记录。

本次修订更新了源码中的安卓界面校验规则，使它与已经实现的高对比度筛选抽屉及分享时参数提示一致。电脑 EXE、安卓 APK 和已签名的更新清单与 beta.1 使用相同字节。

## 本版功能

- 电脑端加入程序自动更新。1.0.39 首次迁移使用完整 EXE；从此版往后，启动时自动检查，优先下载适用的差分包，验证签名和哈希后安装并重启。网络中断可续传，差分不适用时改用完整包。部件图标继续通过独立通道自动增量更新。
- 本地照片参数解码和本地图标包继续使用，动作、光照与滤镜图标可在分享图中显示。完善参数缺失和连接错误的对应提示。
- 安卓端新增「最近拍摄」分组，把同步后新增的一组照片放在图库顶部，支持右侧全选并批量保存；该组保留到下一组新照片出现。首次同步旧相册只建立基线。
