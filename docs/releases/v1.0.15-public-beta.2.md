# 大喵相机助手 1.0.15 公测版

Windows 1.0.15 / build2026102204，Android 1.0.15 / versionCode39。提供 Windows EXE、独立 APK 和统一公测 ZIP；EXE 内置的 APK 与独立下载完全一致。

## 首次使用与相册目录

- 首页新增首次使用引导，顶部集中导出安卓安装包、连接排障和添加扫描目录三个快捷按钮。
- 目录选择说明改为明显的按钮，可展开、收起；从首页添加目录入口进入时自动展开。
- 支持额外扫描目录，为搬迁相册、旋转吧大喵和普通截图/修图导出选择实际照片文件夹。最多16个目录，包含子目录，重启后保留。
- 先识别预览，确认后才加入本机共享相册；移除只停止扫描和分享，不删除电脑原文件或手机已保存副本。
- 提供 GamePlayPhotos、UID、原图/缩略图和旋转吧大喵输出位置的说明，避免选错缩略图或扫描整个磁盘。外部截图可能没有游戏穿搭/拍摄参数，普通录像不会自动组成 LIVE。
- 发布检查补充了 Windows 短目录名/完整路径和目录别名的兼容，避免同一相册重复添加，正确恢复中断的目录移除；保留原有资产和资源路径标识。
- 暂时隐藏未完成的微信小程序入口。

## 连接与保存

- 改善多网卡、手机热点下的地址优先级，刷新二维码与服务发现地址；手机可从已验证的候选地址恢复连接，保留原配对与证书校验。
- 同步设置提供可选的“允许手机连接”：确认 Windows 提示后，为当前后台同步服务添加限本地子网的 TCP 授权，也可撤销。已经正常连接时无需操作，不关闭防火墙。
- 网络授权不能解除校园网、公共 Wi-Fi 的设备隔离；授权后仍失败可改用手机热点测试。
- 华为默认选择华为 LIVE 格式，荣耀单独识别并使用相应兼容方案，保留用户手动选择。
- 完善大分辨率 LIVE 导出、旋转及封装校验，保留内存/大小保护，不降低原图清晰度。
- 统一照片保存目录与发布时的日期处理，保留拍摄日期和参数；保留液态玻璃、动态预览、EXIF、分享图及 Android 11/12 兼容。

## 下载与更新

- `MomoCamera-PublicBeta-1.0.15.zip`：完整用户包，包含 EXE、APK、使用说明、更新说明和 SHA256SUMS。
- 只更新手机时，下载 `MomoCamera-Android-1.0.15.apk` 覆盖安装。APK 与前一份1.0.15一致，沿用近期公测签名；已经安装1.0.15的手机无需再装。
- 不要先卸载或清除数据。更早不同签名的版本请先反馈迁移需求。
- 更新电脑前，从右下角托盘退出旧助手，再运行新版 EXE。连接超时时到“同步设置 → 本地网络权限”检查当前版本的授权。
