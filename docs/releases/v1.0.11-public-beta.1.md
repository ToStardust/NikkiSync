# 大喵相机助手 1.0.11 公测版

Windows 1.0.11 / build2026102102；Android 1.0.11 / code35。此完整包合并 Android 11/12 适配、局域网连接修复及大相册首次启动修复，电脑 EXE 内置与独立下载文件完全相同的 APK。

## Android 11 / 12

- 最低支持 Android 11（API 30），targetSdk / compileSdk 保持 35。
- 修复旧系统启动时直接调用 Android 13 照片选择器 API 的错误，修图选图通过 AndroidX 回退到旧系统可用的选择器。
- 修复旧系统局域网发现等待不存在的附近 Wi-Fi 权限的问题；保留隐私同意和扫码相机权限流程。
- Android 11 保留半透明玻璃面板、边框、遮罩及导航；Android 12 及以上保留 GPU 背景模糊。
- 补齐 Java 字符串、集合、流和文件读取兼容，覆盖离线文档、EXIF、LIVE 封装及图片处理。完整兼容库许可证和 Classpath exception 随 APK 保留。
- JPEG 分块旋转后备路径使用 Android 11 可用的流式解码接口，完整解码期间保持输入流打开。原有尺寸、画质及内存约束保持不变。

## 连接与首次启动

- 配对与服务发现共用局域网地址选择逻辑，避免明显的虚拟/仅主机网卡优先；正常物理 172 网段继续支持。
- 切换网络后刷新服务发现、新配对二维码及微信新分享会话使用的地址。
- 修复大相册持续扫描时，两分钟等待到期就被终止的问题。启动页现在显示文件数量、累计读取量和索引阶段；GamePlayPhotos 历史账号仍完整扫描。
- 只有实际进展才延长等待；重复或无效计数不延长。连续两分钟无进展仍报超时，后台启动总上限为三十分钟。
- 修复点击“重试启动”时重复传入新 WebView2 环境的错误，复用成功初始化的界面组件。
- 增加不包含路径、UID、照片参数或凭据的后台数值进度日志，便于继续定位异常。

## 下载与升级

- 完整 ZIP 包含 EXE、APK、README、更新说明和 SHA256SUMS。独立 EXE / APK 同时提供下载。
- Windows 请从托盘退出旧助手后运行新 EXE，或使用“关于 → 检查更新”的签名更新流程。配对、设置与索引保留。
- Android 沿用近期匿名公测签名，可覆盖同签名旧版；已安装本地 Android 1.0.11 的用户无需重装手机端。签名冲突时请保留原 App 与数据并反馈确认迁移方式。
- 只覆盖手机 APK 不会替换电脑后台；连接修复及启动修复需要更新电脑 EXE。
- HarmonyOS / OriginOS 等厂商系统以实际 Android API 为准。多个真实局域网、VPN 路由及防火墙互访情况仍需现场验证。

保留原图、EXIF、LIVE 保存/旋转、实时同步、自动重连、参数分享图、已保存照片、关联修图和小组件。在线参数解析默认开启，可在电脑同步设置关闭；开启时向第三方发送游戏 UID、编码参数与校验值，不上传源照片字节。
