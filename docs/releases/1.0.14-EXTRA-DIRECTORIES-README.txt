大喵相机助手 · 额外扫描目录测试版
电脑版本 1.0.14 · 构建号 2026102201

使用方法：
1. 从电脑右下角托盘中退出旧助手，打开本包 MomoCamera-PC-1.0.14-ExtraDirectories.exe。
2. 进入“同步设置 → 额外扫描目录”，点击“添加文件夹”。
3. 选择实际保存照片的文件夹，核对识别结果后点击“确认加入共享相册”。可重复添加多个目录，最多16个，重启后保留。
4. 等待扫描完成，在已连接手机上查看新照片。Android App 不用重新安装或重新配对。

如何选目录：
- 旋转吧大喵：在该软件“设置 → 输出目录”查看实际位置。默认通常为系统“视频”下的 SpinningMomo；改过位置请以软件设置为准。助手提供了单独的选择入口。
- 搬迁的游戏相册：推荐选择 GamePlayPhotos 或其中的 UID 文件夹。助手会同时识别原图、缩略图和完整 LIVE。
- 只想加入静态原图：可选择 NikkiPhotos_HighQuality。不要选择 NikkiPhotos_LowQuality，它是缩略图。
- 也可选择搬迁后的游戏根目录或 X6Game，助手会定位其中的媒体文件夹，避免扫描游戏包。
- 普通截图/修图导出：选择实际保存图片的目录。包含子文件夹，支持 JPG/JPEG、PNG、WebP；不把普通 MP4 录像当作 LIVE。

范围说明：
确认前只预览目录；确认后文件会加入这台电脑的共享相册，所有已配对的设备都可访问。
不会复制或改写电脑原文件。移除目录只停止扫描和分享，不删除电脑原文件，也不删除手机已经保存的副本。
已被默认相册或其他目录覆盖的文件夹不重复加入。不同文件夹的同名照片互不覆盖。
目录暂不可读或移动硬盘离线时保留索引。恢复磁盘连接后可点“重新扫描”。
修改目录后，Android App 自动同步；已打开的微信相册连接需重新生成，以应用新的共享范围。

照片参数说明：
游戏原生照片保留原有参数解析链路。软件截图或修图导出不一定包含游戏元数据，不能凭图片补出缺失的穿搭与拍摄参数。
PNG/WebP 可以浏览和原样保存；手机端目前的旋转保存针对 JPEG。普通录像不会自动组合成 LIVE。

网络权限：
上个测试版的授权查询错误已修复，并已有用户反馈授权后成功连接。
入口现放在“同步设置 → 本地网络权限”，主界面保留前往设置的提示。
只有遇到连接问题时才需要操作；已能正常连接的用户无需重新授权。Windows 提示时选择“是”。
授权只允许本地子网访问当前后台服务的同步 TCP 端口，可在设置中撤销；不关闭防火墙。

本测试包只需替换电脑 EXE；内置 APK 沿用原 1.0.14 匿名签名版，手机数据、电脑配对和已有设置保留。
