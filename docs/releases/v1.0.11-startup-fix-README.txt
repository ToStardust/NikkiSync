大喵相机助手 · 首次启动修复测试版
电脑版本 1.0.11 / 构建 2026102102，2026-10-21

适用于首次启动停在扫描阶段或点击“重试启动”后界面组件失败的反馈。

使用方法
1. 解压此压缩包。
2. 从电脑托盘退出旧助手，再运行本文件夹内的 MomoCamera-PC-1.0.11.exe。
3. 大相册首次启动时，请保持程序运行，观察“已检查文件数”和“已读取量”。
4. 等待主界面出现，再用手机配对或同步。已有配对与设置保留，无需删除照片、GamePlayPhotos 或数据目录。

修改内容
- 扫描持续有实际进展时，不再到两分钟就强制终止；会显示文件数量、累计读取量和索引阶段。
- 连续两分钟无进展仍会报超时；后台启动的总等待上限为三十分钟。
- 点击重试时复用已成功初始化的界面组件，避免重复传入新 WebView2 环境。
- 失败提示补充后台阶段日志文件名，便于进一步定位。

读写校验方式没有精简，也不会忽略历史账号。累计读取量包含不同校验步骤的重复读取，可能大于相册实际容量。

本包仅更新电脑 EXE；内置 Android 1.0.11 安装包与此前已测试的 Android 11/12 兼容版本完全相同，手机无需为本次电脑修复重新安装。
此前局域网地址选择、二维码刷新修复继续保留。

若仍失败，请在再次重试前，通过“打开日志文件夹”反馈：
startup-diagnostics.log、game-discovery.log、startup-timings.json、startup-service-timings.json。
不要把数据库、整个数据目录或照片一起发送。

这是本地测试包，尚需反馈者在约 40 GB 的实际相册上复测；本地受控验证不能替代现场验收。
