# 大喵相机助手 1.0.25 公测版

**请将电脑端和手机端一起更新。** Windows 1.0.25 / build2026102502，Android 1.0.25 / versionCode49。EXE 内置 APK 与独立下载相同，沿用原匿名公测签名。

## 更新内容

- 移除图库读取到 2 万张即停止的限制，改善大相册加载和离线整理。
- 小缩略图与高清预览分开缓存，照片没变就复用；在线打开照片自动加载高清。设置可调整缓存容量、图片内存上限，并查看、暂停或继续离线补图。
- 最近删除改为手机整批核对一次。电脑确认后，保持手机 App 打开完成本批核对；显示“本批已核对”后可关闭 App，由电脑继续批量移入回收站。
- 减少重复扫描、哈希和逐文件启动回收程序；保留文件变化检查，变化的文件不删除。所有删除只进入 Windows 回收站，可从回收站恢复。
- 修复部分大图无法显示待删除预览，增加预览缓存和重试；修复参数更新后误报“照片已变化”，以及移除扫描目录后残留副本引用的问题。
- 结果同步到手机后收起旧失败提醒，也可点“移除失败提示”。失败不会自动重试；仍需删除的照片，重新同步后再选择。清理提示不会删除照片。

## 下载与更新

- 完整包：`MomoCamera-PublicBeta-1.0.25.zip`，含 EXE、APK、使用说明、更新说明及 SHA256 校验文件。
- 先从右下角托盘退出旧电脑助手，再运行新版 EXE。窗口右上角 × 仅隐藏到托盘。
- 手机覆盖安装新版 APK，保留配对、缓存和整理记录；请勿卸载或清除数据。旧签名版本冲突时，请保留原数据并通过项目仓库反馈。
- 离线整理需先完成相应照片的缓存；超过缓存容量时可在设置提高上限。未缓存的原图、LIVE 或拍摄参数仍需连接电脑。
