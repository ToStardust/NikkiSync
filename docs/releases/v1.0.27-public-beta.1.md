# 大喵相机助手 1.0.27 公测版

**请电脑端和手机端一起更新。** 电脑先从托盘退出旧版，再打开新版；手机直接覆盖安装，无需卸载或清除数据。

- 合入已验证的电脑启动修复，改善缩略图缓存续传和重复加载。
- 小缩略图默认缓存上限改为 **2GB**，保留手动选择的容量；首页同时显示“已同步”和“已缓存”张数。
- 电脑“同步设置 → 同步与连接 → 同步账号设置”可按 UID 勾选，并显示照片示例；额外添加的“旋转吧大喵”输出目录也可单独选择。旧自定义输出目录可在“额外扫描目录”补充来源标记。
- 图库和已保存支持类型、UID、来源文件夹筛选；首页搜索大胶囊右侧为筛选小胶囊。筛选保留底部抽屉，选项直接展开，目录留出间距并自动换行。
- 照片预览的多选按钮改为圆形；详情增加 UID、可展开复制的源文件路径及图片尺寸、文件大小。
- 补充游戏 2.11 版本资料，完善官方版本信息自动检查；无法联网时保留已有日历。

同步范围调整不会删除电脑源照片。手机完成同步后会移除未共享账号的图库缓存，已保存照片、修图关联和最近删除记录保留。离线整理前请先等待缓存就绪。

本包包含 Windows **1.0.27 / 2026102703**、Android **1.0.27 / 53**，EXE 内置 APK 与独立 APK 相同。沿用已完成的 Android、PC、Windows 回归及实际 EXE 启动、来源标记、目录移除和服务恢复检查；不同机型的显示与 LIVE 兼容性仍以实际体验为准。
