# 大喵相机助手 1.0.8 公测版

Windows 1.0.8 / build2026102001；Android 1.0.8 / code32。

本次调整照片 EXIF 的字段对应关系：**相机型号 MomoCamera，镜头型号 Infinity Nikki**。镜头厂商继续记录照片所属游戏版本的英文标题（例如 2.9 为 Bloom Beneath Bright Skies）。电脑导出、手机普通照片保存和关联修图保持一致，已有照片不会自动改写。

保留 1.0.7 自动重连和实时同步修复，以及 LIVE 动态预览、分享图、已保存照片、关联修图、小组件和在线参数解析设置。

## 下载与升级

- 统一公测 ZIP 包含 EXE、APK、使用说明、更新说明及 SHA-256 校验文件，电脑助手内置同版 APK。
- Windows 退出旧助手后运行新版 EXE，保留配对、设置和索引；“关于 → 检查更新”也可通过签名更新源下载、校验并重启替换程序。
- Android 13 及以上可用；1.0.5 新公测签名及 1.0.6、1.0.7 可直接覆盖安装。其他签名的旧版本请先确认迁移方式，不要直接卸载或清数据。
- [百度网盘订阅文件夹](https://pan.baidu.com/s/5bb_o2A8iJ2MR4f_hRBlPCw)继续提供下载入口；仅上传网盘不会触发签名一键更新。

在线参数解析默认开启，可在电脑同步设置关闭。开启时向第三方提供游戏 UID、编码参数及校验值，用于补全拍摄与搭配参数。
