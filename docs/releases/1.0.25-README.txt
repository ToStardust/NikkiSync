大喵相机助手 1.0.25 测试版

电脑端：MomoCamera-PC-1.0.25.exe
手机端：MomoCamera-Android-1.0.25.apk

两端请一起更新。电脑先从托盘退出旧助手，再打开新版 EXE；手机覆盖安装 APK，保留现有配对、保存记录与整理数据。电脑端也能导出同一份 APK。

首次使用：打开电脑助手，按引导完成相册扫描；手机与电脑连接同一网络，安装 App 并扫描电脑配对码。连不上时可在同步设置检查本地网络权限，或尝试临时组网；扫码页可导出连接诊断压缩包。

离线整理：在线时保持 App 在前台补齐小缩略图，可在设置查看进度、暂停或调整容量。外出时可查看已缓存照片并标记待删除，待删除记录与预览独立保留。

回到电脑后：手机打开 App 并连接电脑 → 电脑“最近删除”确认本批 → 手机在线核对一次。显示“本批已核对”后可关闭 App，电脑继续处理。文件只移入 Windows 回收站，可从回收站恢复；不影响手机另存的照片。

取消与失败：开始回收前可取消待删除；开始后请从电脑回收站恢复。文件已变化或无法安全回收时保留原文件，不会自动再删。重新同步后可重新选择；电脑“移除失败提示”只收起记录。
