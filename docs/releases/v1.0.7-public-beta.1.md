# 大喵相机助手 1.0.7 公测修复版

Windows 1.0.7 / build2026101903；Android 1.0.7 / code31。

## 更新

- 修复旧热点地址未及时切换、局域网发现失败后不重试、后台返回后连接未恢复，以及重新连上后图库没有补载的问题。
- 电脑mDNS在热点/Wi-Fi地址变化后刷新广播；Android兼容发现服务类型的格式差异，串行解析并忽略旧网络回调。
- 修复生产HTTPS实时同步握手超时：EXE改用Bun1.4.1 baseline，保持较老CPU支持，并增加相同运行时的TLS回归测试。
- 实时连接加入空闲心跳和超时恢复，分别提示网络不可达、配对拒绝或证书变化。
- 在线参数解析默认开启，可在电脑同步设置关闭，保留已有明确关闭选择。开启时向第三方提供游戏UID、编码参数及校验值，用于补全拍摄与搭配参数。
- 两端内置百度网盘下载与订阅入口；电脑签名一键更新保留，手机仍由用户下载APK后确认安装。

继续包含1.0.5的LIVE静音动态预览、vivo保存修复、已保存清晰原图、小组件、固定英文EXIF、版本英文名称、关联修图与参数快照、关于与仓库入口。

## 下载与更新

统一ZIP包含Windows EXE、Android APK、使用说明、更新说明和校验文件。Windows也内置同版APK。

电脑可在“关于”中使用已发布的签名更新源下载、校验并重启更新，保留配对、设置与索引；也可退出旧助手后运行新版EXE。不要删除用户数据目录。

1.0.5新公测签名及1.0.6可覆盖安装此APK；其他签名旧版请先确认迁移方式，不要直接卸载或清数据。

百度网盘：https://pan.baidu.com/s/5bb_o2A8iJ2MR4f_hRBlPCw 。仅上传网盘不会触发签名一键更新。

附NikkiGallery技术交接包，按当前本机功能整理近期变化、协议兼容要求、源码位置和联调清单；未修改对方工程。
