# 大喵相机助手 1.0.31 公测更新

**电脑端和安卓 App 请一起更新。电脑从托盘退出旧版再打开新版，手机直接覆盖安装，无需卸载。**

## 微信小程序开始测试

苹果用户可以通过微信小程序连接电脑，浏览照片、保存原图和视频、查看穿搭与拍摄参数，并制作分享图。支持旋转保存照片和视频，以及同步灵感库中的码和参考图。电脑助手需保持运行，手机和电脑需处于可互通的 Wi-Fi 或热点网络。

兼容版电脑端已内置打开小程序的入口码，首次默认展开，以后可折叠。用微信扫描入口码打开小程序，再在小程序内扫描电脑生成的临时连接码。

## 本次更新

- 电脑端分为仅 App 版和兼容小程序与 App 版，两版沿用相同的数据目录、配对记录和同步设置。
- 安卓图库支持滑动连续多选、滑动到边缘继续选择，以及对当前筛选结果按版本全选。
- 灵感库参考图完整显示，可直接点击查看大图；电脑、App 和小程序支持同步码与参考图。
- 已保存照片在系统相册被删除后会标记状态，电脑仍有原图时可以重新保存；修复失效预览和错误打开其他照片的问题。
- 改善额外目录、云端照片的日期与版本判定，排除 pendingup 临时缩略图，减少低清图片被误当原图收录。
- 合入小程序临时连接、穿搭分享、批量删除和图标缓存等调整；新的图标缓存需配套更新后的小程序代码。

临时热点组网、多 UID 与多文件夹同步、离线整理、待删除确认和染色码粘贴提取功能继续保留。离线整理需提前缓存照片。删除电脑照片需要电脑确认和手机完成核对，只移入 Windows 回收站；手机已保存的照片不受影响。
