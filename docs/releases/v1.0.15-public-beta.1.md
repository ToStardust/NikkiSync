# 大喵相机助手 1.0.15 公测版

Windows 1.0.15 / build2026102203，Android 1.0.15 / versionCode39。提供 Windows EXE、独立 APK 和统一公测 ZIP；EXE 内置的 APK 与独立下载完全一致。

## 首次使用与相册目录

- 首页新增“首次使用引导”，顶部集中导出安卓安装包、连接排障和添加扫描目录三个快捷按钮。
- “不知道该选哪个文件夹？”改为明确按钮，可展开、收起说明；从首页添加目录入口进入时自动展开。
- 同步设置支持额外扫描目录：为搬迁相册、旋转吧大喵和普通截图/修图导出选择实际照片文件夹。最多16个目录，包含子目录，重启后保留。
- 添加前先识别预览，确认后才加入本机共享相册；移除仅停止扫描和分享，不删除电脑原文件或手机已保存副本。
- 提供 GamePlayPhotos、UID、原图/缩略图与旋转吧大喵输出位置的说明，避免选错缩略图或扫描整个磁盘。外部截图可能没有游戏穿搭/拍摄参数，普通录像不会自动组成 LIVE。
- 暂时隐藏未完成的微信小程序入口。

## 连接与启动

- 改善多网卡、手机热点下的地址优先级，刷新二维码与服务发现地址；手机可从已验证的候选地址恢复连接，保留原配对与证书校验。
- 同步设置新增可选“允许手机连接”：确认 Windows 提示后，为当前后台同步服务添加限本地子网的 TCP 授权，也可撤销。已经正常连接时无需操作，不关闭防火墙。
- 引导说明校园网、公共 Wi-Fi 可能隔离设备；网络授权不能解除路由器隔离，可改用手机热点测试。
- 保留前版首次启动进度、失败恢复、Android 11/12 兼容和已有数据保留机制。

## 合并近期手机端修复

- 华为默认选择华为 LIVE 格式，荣耀单独识别并使用相应兼容方案，保留用户手动选择。
- 完善大分辨率 LIVE 导出、旋转与封装校验，保留内存/大小保护，不降低原图清晰度。
- 统一照片保存目录和发布时的日期处理，保留拍摄日期及参数；保留液态玻璃、动态预览、EXIF 和分享图功能。
- 1.0.15 本轮主要调整电脑端引导；APK 统一版本号并沿用近期公测签名。各厂商系统相册 LIVE 识别与播放仍需实机确认。

## 下载与更新

- `MomoCamera-PublicBeta-1.0.15.zip`：完整用户包，内含 EXE、APK、使用说明、更新说明和 SHA256SUMS。
- 只更新手机时，下载 `MomoCamera-Android-1.0.15.apk` 覆盖安装即可。不要先卸载或清除数据；更早不同签名的版本请先反馈迁移需求。
- 更新电脑前，从右下角托盘退出旧助手，再运行新版 EXE。连接超时时到“同步设置 → 本地网络权限”检查当前版本的授权。
- 百度网盘订阅目录：https://pan.baidu.com/s/5bb_o2A8iJ2MR4f_hRBlPCw
