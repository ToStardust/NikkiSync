大喵相机助手 1.0.15 公测更新

- 首页改为“首次使用引导”，提供导出安卓安装包、连接排障和添加扫描目录的快捷入口。
- 暂时隐藏未完成的微信小程序入口。
- “不知道该选哪个文件夹？”改为明确的按钮，可展开或收起目录说明；从首页添加目录入口进入时会直接展开。
- 保留同步设置内的本地网络授权，以及额外扫描目录的预览确认、多目录、重启保留和移除保留原文件功能。
- 保留此前的 Wi-Fi/热点地址选择、多地址重连、启动恢复、华为/荣耀 LIVE 格式选择及大文件保存修复。
- Windows 与 Android 统一版本 1.0.15。电脑端内置的 APK 与本包独立 APK 完全一致。
- 发布检查补充：兼容 Windows 目录短名与完整路径，防止同一相册重复添加，并恢复别名路径下中断的目录移除。电脑构建号 2026102204。

本轮调整集中在电脑端引导与入口；手机端统一版本号，功能沿用前版。
