大喵相机助手 1.0.21 · 批量删除优化测试版

更新方法
电脑从托盘右键退出旧助手，再运行本包 EXE。
手机覆盖安装本包 APK，不要卸载或清除数据。
建议电脑和手机一起更新，才能获得完整的处理进度与快速核对体验。
沿用公测签名，保留原有配对、设置、缓存和整理记录。

批量删除
手机标记 → 电脑核对关联文件 → 一次全选确认 → 手机自动核对 → 移入 Windows 回收站。
核对尚未全部完成时，“全选”按钮暂时显示核对进度；完成后再确认整批。
确认后请保持手机 App 打开并连接当前电脑。进度自动更新，无需反复点击。
等待、核对阶段仍可取消；已经开始移入回收站的照片，可在电脑回收站恢复。
长时间断线时，尚未开始的照片会暂停，重连后重新确认。
手机已保存的照片不受影响。

本次优化
整批共享截图目录核对，减少重复读取整个相册。
耗时处理在电脑后台执行，手机同步和取消操作继续响应。
处理期间合并扫描事件，避免每移动一个文件都重复扫描相册。
相同截图被多条记录关联时，同一批次只回收一次，不要求反复确认。
电脑显示核对、排队、移入回收站等进度，并复用照片预览。

保留前版的照片参数缺失说明、离线排序、临时组网和额外扫描目录等功能。
