# 大喵相机助手 1.0.22 公测版

Windows 1.0.22 / build2026102403，Android 1.0.22 / versionCode46。EXE 内置 APK 与独立下载相同。

## 自启动修复

- 修复手动更换新版 EXE、改名或移动文件夹后，开关显示开启却无法开机启动的问题。
- 已开启自启动时，新版首次运行会将本应用的启动项更新为当前 EXE 路径，无需反复关闭再开启。原本关闭的选择保持关闭。
- 无法读取或保存启动项时显示提示，不再把旧路径当作当前版本已开启；不会修改其他程序的启动项或 Windows 的禁用记录。

## 连接修复

- 修复防火墙规则同名时，出现“检测到冲突，但零条可自动处理”的问题。现在按程序、协议、端口和范围等完整特征核对，精准选择当前助手的 TCP 规则。
- 保留同名 UDP、其他程序、其他端口和域网络规则；仍有歧义、受管理或附带复杂限制的规则继续跳过。修改前保留恢复记录，可撤销修复。
- 此次修复已获得反馈用户确认可用，其他网络环境仍需分别验证。

## 一键导出连接诊断包

- 二维码配对页面及“生成新二维码”弹窗新增“连接失败？导出诊断包”。选择保存位置，即可把生成的 ZIP 发给开发者，无需手机先连接。
- 自动整理电脑连接检查、版本/构建号、当前运行中最近一次修复结果，以及筛选后的启动日志。
- 不收集照片、配对码、密钥、数据库、个人路径、用户名、MAC 地址或 Wi-Fi 名称，不自动上传，不修改网络或防火墙。
- 日志缺失、损坏或部分检查无法完成时，仍保留已收集的信息，并标明未完成项目。
- 反馈时请附手机型号、App 版本、连接方式和手机端报错截图。
