# 大喵相机助手 1.0.10 公测版

Windows 1.0.10 / build2026102002；Android 1.0.10 / code34。

修正新导出照片的 EXIF 名称：**相机型号 `MomoCamera`，镜头型号 `InfinityNikki`**。去掉与型号重复的相机厂商字段，避免部分相册显示两个 MomoCamera。电脑导出、手机普通照片保存与关联修图保持一致；镜头厂商继续记录照片所属游戏版本的英文标题。已有保存照片不会自动改写，用于原生 LIVE 识别的厂商封装保持原逻辑。

同时合并 1.0.9 的 LIVE 旋转保存修复：大尺寸封面优先进行 JPEG 压缩系数变换，有限内存配合磁盘缓存处理，不规则边缘使用完整尺寸后备路径。手机不支持目标视频编码尺寸时会明确提示，可恢复原方向保存。

保留自动重连、实时同步、默认静音动态预览、穿搭与参数分享图、已保存照片、关联修图、小组件及现有参数关联。

## 下载与升级

- 统一 ZIP 含 EXE、APK、使用说明、更新说明及 SHA-256 校验文件；电脑助手内置同版 APK。
- Windows 从托盘退出旧助手后运行新版 EXE，或在“关于 → 检查更新”中使用签名一键更新，保留配对、设置与索引。
- Android 13 及以上可用。沿用 1.0.5 后公测签名的版本可覆盖安装；签名不一致的旧版请保留原 App 与数据，先反馈确认迁移方式。
- [百度网盘订阅文件夹](https://pan.baidu.com/s/5bb_o2A8iJ2MR4f_hRBlPCw)作为手动下载入口；本次 GitHub 同时发布签名更新清单，电脑的一键更新仍校验签名、大小与哈希。

在线参数解析默认开启，可在电脑同步设置中关闭；开启时向第三方发送游戏 UID、编码参数与校验值，以补全拍摄及穿搭信息。

## 验证

Android 单元回归 306 项、PC/core 157 项、EXIF/LIVE 导出 13 项、Windows 59 项、便携/主题 10 项和实际 Bun 1.4.1 生产 TLS 握手回归通过。最终 EXE 隔离启动、实际版本、内置 APK 一致性与更新签名验证通过。

合并的 LIVE 修复已通过 4K、6K、8K、16K JPEG 封面压力验证，以及真机 48 组 EXIF/旋转/边缘尺寸组合与取消清理测试。原问题 4K LIVE 实机旋转后保存为完整 2160×3840，封面转回像素一致，视频 151 帧保持不变。这些结果不代表所有手机都能编码 8K/16K LIVE 视频，也不代表所有系统相册都已验证。

视频物理旋转仍需重新编码；JPEG 封面优先使用系数变换，不规则边缘可能重编码 JPEG，保留完整尺寸。
