大喵相机助手 · 网络授权测试版
电脑版本 1.0.14，构建号 2026102107（授权修复测试版）

用于排查手机连接热点后，电脑防火墙未放行同步服务的情况。

请这样测试：
1. 保持手机热点开启，电脑连接这个热点。
2. 在电脑右下角托盘中，右键旧版“大喵相机助手”并选择“退出”。仅关闭窗口仍会在托盘运行。
3. 解压本测试包，打开 MomoCamera-PC-1.0.14-NetworkFix.exe。
4. 在“手机连接”页的 Android App 卡片中，点击“连接排障：允许手机连接”。已有手机能正常连接的用户无需执行授权。
5. Windows 提示是否允许更改设备时，选择“是”。系统可能显示未知发布者，请确认是刚打开的本测试版。
6. 电脑显示“已添加本地网络连接权限”后，在手机 App 中重新扫码连接。
已检测到本工具为当前服务添加的权限时，按钮会显示“已添加本地网络权限”，不用反复点击。
如果助手本来就以管理员权限运行，Windows 可能直接完成操作而不再弹出授权提示。

成功后请反馈“授权后可以连接”，并试一下浏览照片、预览 LIVE 和保存照片。
如果仍失败，请反馈按钮下方的完整提示，以及重新运行连接诊断工具后生成的报告。

本次只需替换电脑 EXE。内置安卓安装包仍为原来的 1.0.14，没有重新签名，无需为本次测试卸载或重装手机 App。
此版修复上一测试版查询不存在规则时提前失败的问题；失败提示会包含 NET-AUTH 阶段代码，便于继续定位。
保留现有照片、配对、设置和相册索引；也不会修改游戏文件。

授权范围：当前版本实际后台服务、同步 TCP 端口、本地子网、Windows 专用/公用网络。
不关闭防火墙，不开放任意程序或任意端口，不修改 Wi-Fi/热点设置，也不修改组织管理的域网络规则。
只有点击按钮并获得 Windows 授权后才添加规则；取消授权不会添加。重复点击不会重复添加同一条规则。
“同步设置 → 本地网络权限”可以撤销本工具为当前服务添加的规则。
更新后后台服务路径可能变化；若更新后再次连接失败，可以重新点击授权。

如果电脑管理策略禁止本地规则，或者网络本身隔离设备，此授权不能绕过这些限制；请反馈诊断信息继续排查。
