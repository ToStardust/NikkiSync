大喵相机助手 1.0.23 公测版

更新方法
先在电脑右下角托盘中右键助手，选择“退出”，再解压运行新版EXE。点窗口右上角×只会隐藏到托盘，可能仍在运行旧版。
可在电脑窗口底部查看当前版本和构建号：1.0.23 / 2026102408。
电脑EXE内置的APK与压缩包中的独立APK相同。手机可覆盖安装同签名的近期公测版，不要卸载或清除数据；已有1.0.22手机App也可继续使用。
原有配对、设置、缓存和整理记录保留，不需要清空数据库或重新选择相册。

首次扫描失败
本版修复LIVE封面误配其他照片视频，导致重复路径入库和启动失败的问题。
遇到缺少视频、跨目录或配对歧义的素材，不再猜测关联；旧失败留下的同类错误关联会在核对来源和校验值后定向纠正。
不会搬动或删除原照片。首次相册较大时，请等待扫描和入库完成。

连接或照片列表突然不可用
电脑窗口底部固定提供“重启同步服务”和“导出诊断包”，切换页面或网页失效时也可使用。
可先导出诊断包，再点“重启同步服务”，恢复后让手机重新连接。这个操作保留配对和照片数据。
启动过程中也可以导出诊断。请等待保存成功，把生成的ZIP和问题截图发给开发者。
诊断仅包含筛选后的版本、后台状态、扫描计数、错误分类和连接检查；不包含照片、数据库、配对码、密钥或个人路径，不会自动上传。

已保存的手机照片不受电脑端索引整理影响。删除电脑照片仍需确认且仅移入Windows回收站，可从回收站恢复。
后续更新可查看“关于”中的GitHub和百度网盘订阅目录。
