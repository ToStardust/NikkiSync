Android 11 / 12 兼容
- 最低系统要求从 Android 13 调整为 Android 11（API 30）。
- 修复旧系统启动时直接调用 Android 13 照片选择器接口导致的错误。
- 修图关联选择器通过 AndroidX 使用旧系统的文件选择器，无需整个相册读取权限。
- 修复 Android 11 / 12 局域网发现等待不存在的附近 Wi-Fi 权限的问题。
- Android 11 对不支持的背景模糊接口安全降级，保留面板、文字可读性和导航交互。
- 修复离线文档、EXIF、LIVE 封装校验和图片处理中的高版本 Java 文件读取调用。
- 通过 Java 标准库兼容库支持旧系统上的字符串、集合和流 API。
- 全分辨率 JPEG 分块旋转使用 Android 11 可用的解码接口，明确关闭输入文件。

电脑助手
- 内置与独立文件完全相同的 1.0.11 APK。
- 合入本地已完成的局域网地址选择修复，避免明显的虚拟/仅主机网卡优先，刷新新配对二维码的当前地址。
- 网络切换后更新服务发现地址；微信新分享会话也使用当前地址，正常物理 172 网段继续支持。
- 多个真实局域网并存、VPN 路由和防火墙是否允许互访仍需要实际网络验证。

首次启动与重试
- 修复较大 GamePlayPhotos 相册持续扫描时，两分钟等待到期就被终止的问题。
- 启动页显示已检查文件数、累计读取量和建立索引阶段；完整扫描、文件校验及历史账号识别保持原逻辑。
- 仅实际进展会延长等待，重复或无效进度不延长；连续两分钟无进展仍超时，后台启动总上限为三十分钟。
- 修复点击“重试启动”时，为已初始化的 WebView2 再传入新环境导致界面组件失败的问题。
- 补充后台数值进度日志与失败页日志提示，不记录照片内容、UID、文件路径、配对码或密钥。

保留
- 继续使用近期匿名公测签名，可在同签名版本上覆盖升级。
- 保留照片、配对、收藏、昵称、缓存与现有导出参数。
- 保留原图、EXIF、LIVE 封装和原生 JPEG 旋转功能，不改写既有照片。

测试与限制
- API 扫描无兼容性错误；自动化覆盖 Android 11、12、12L 和当前目标系统。
- 覆盖启动、选图、权限、局域网发现与重连、扫码、身份密钥、照片显示、EXIF、保存记录、LIVE 核心和桌面相框。
- Android 完整回归 487 项通过；Lint 0 错误，保留 105 个既有警告；设备测试 APK 编译通过但未执行。
- PC/core 167 项、Windows 67 项、封装/主题 10 项回归通过；Windows 包括真实隔离 WebView2 重试后的脚本执行。
- 完整 EXE 经受控慢扫描约 133 秒后成功打开主界面；此测试使用独立合成文件，不代表反馈者约 40 GB 实际相册已验收。
- 本机未连接反馈用户的手机；本地 x86_64 模拟器缺少可用硬件加速，未完成设备级测试。
- 厂商相册是否识别 LIVE、实际视频硬件编码能力和原反馈用户网络均未宣称验收通过。

升级与下载
- Windows 从托盘退出旧助手后运行新 EXE，或使用“关于 → 检查更新”的签名更新流程；保留配对、设置和索引。
- 手机沿用近期匿名公测签名，可直接覆盖同签名旧版；签名冲突时请保留原 App 与数据并反馈，勿直接卸载。
- 已安装 Android 1.0.11 的用户无需为电脑启动修复重新安装手机端。
