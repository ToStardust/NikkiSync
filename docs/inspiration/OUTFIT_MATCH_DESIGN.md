# Outfit Match Design

## Match levels

### Exact

Known clothing set matches exactly.

### Component

Important clothing parts overlap.

### Similar

Partial overlap with explanation.

## Result format

Do not show only a percentage.

Example:

```
Matched 6/8 parts
Same:
- dress
- hair
- shoes

Different:
- earrings
- handheld
```

## Existing photo search reuse

Reuse NikkiSync clothing and suit indexes.

New logic should only add inspiration-side queries and explainable ranking.

## Ownership rules

A matched photo means "appeared in synced photos".
It does not mean the player currently owns the item.
