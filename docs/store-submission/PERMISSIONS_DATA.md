# 权限与数据申报表

适用1.0.0。以下权限与数据用途按应用实现编写；用户同意隐私告知后才启动连接服务，运行时权限在相应功能触发时请求。

| 权限/机制 | 用途与触发 | 数据范围 | 拒绝影响 |
| --- | --- | --- | --- |
| INTERNET | 配对、照片请求、WebSocket；PC另有公网查询 | 局域网数据请求；外部服务见单独清单 | 不可联网则不能连接PC |
| ACCESS_NETWORK_STATE | 检查网络可用性 | 连接状态 | 普通权限，不提供运行时弹窗 |
| ACCESS_WIFI_STATE | Wi-Fi/发现支持 | 网络状态，非位置用途 | 普通权限 |
| CHANGE_WIFI_MULTICAST_STATE | mDNS组播发现 | 本地服务广播 | 普通权限，不等于任意修改Wi-Fi配置 |
| NEARBY_WIFI_DEVICES | 发现同网络电脑 | 局域网服务标识、地址、端口；neverForLocation | 自动发现受影响 |
| CAMERA | 用户点击扫码配对后 | 相机画面中的配对二维码 | 扫码不可用，可参考已配对重连/其他入口 |
| DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION | AndroidX合并的本包自定义权限 | 应用内部接收器保护 | 不作“读取媒体/定位”的用途申报 |
| 系统选择器/分享content URI | 用户选修图、参考图或外部分享 | 用户授权的文件 | 不选择则不导入 |
| MediaStore | 用户点保存/分享组合保存 | 新导出照片/视频及本应用保存历史核对 | 保存失败明确提示 |

没有声明READ_MEDIA_IMAGES、READ_MEDIA_VIDEO、READ_EXTERNAL_STORAGE、WRITE_EXTERNAL_STORAGE、定位、通讯录、电话、短信、麦克风、AD_ID。无整库读取权限不等于没有读取任何照片。

| 数据 | 保存位置/接收方 | 用途 |
| --- | --- | --- |
| 照片、视频、参数、UID/昵称 | 用户PC索引，手机请求/缓存，主动系统相册导出 | 浏览、搜索、分享与版本分组 |
| 手填昵称、水印、收藏、灵感、修图关联 | 手机私有存储 | 用户设置及整理 |
| 手机随机deviceId、公钥、厂商/型号 | 手机与选定PC | 配对及认证 |
| PC地址、TLS指纹、配对凭据 | 手机私有配置 | 重连和身份校验 |
| PC游戏UID、编码参数、JPEG前缀MD5 | 开启时的NUAN5服务或用户配置解析端点 | 在线解析默认开启，设置中披露并保留关闭选择 |
| 公共资源编号、HTTP请求信息 | 名称/图标提供网站 | 获取公共字典/图片；服务方可见IP与请求 |
| UID及昵称水印、EXIF | 用户导出文件和主动选择的分享接收方 | 用户选择的标识展示，默认开启可关闭 |

数据接收方“用户自己的PC”与“第三方NUAN5”必须分开说明；不能将随机应用标识混同IMEI，也不能在实际发送deviceId/型号时填“完全不处理设备信息”。
