大喵相机助手 1.0.1 公测版

Windows 64位电脑 + Android 13及以上手机。电脑需要已安装电脑版《无限暖暖》，手机和电脑需要在可互访的同一局域网。

首次使用
1. 将 MomoCamera-PC-1.0.1.exe 放进自己的固定文件夹后运行；可独立运行，不要放在压缩包预览中启动。
2. 若提示缺少 WebView2，按程序内的官方安装入口安装 Microsoft Edge WebView2。
3. 将 MomoCamera-Android-1.0.1.apk 发到安卓手机安装；也可在电脑助手内导出相同的APK。
4. 阅读手机隐私说明并选择是否同意，用手机 App 扫描电脑生成的配对二维码。
5. 等待相册同步，即可浏览、查看穿搭参数、保存照片或生成分享图。桌面相框从已保存到手机的照片中取图。

后续更新
电脑助手右上角会显示检查更新/更新至新版本。点击后下载并校验，完成后自动退出旧版并启动新版。只替换原EXE，不删除电脑用户数据、配对密钥、索引、设置或游戏照片；更新期间手机会短暂断开连接。
默认通过 GitHub 获取带签名的更新。若无法连接，可在更新窗口的“国内更新源”填写开发者提供的 HTTPS 清单直链；不要填写普通网盘分享页。无网络或校验失败不会替换原程序。
手机APK仍需由你点击安装更新，不会静默安装。

旧版用户
已有正式签名的1.0.0可使用此正式APK覆盖升级。旧debug测试版与正式版签名不同，系统可能拒绝覆盖：请先联系开发者确认数据迁移，不要直接卸载清空收藏、昵称等私有数据。
电脑旧EXE没有自动更新功能，本次需退出托盘里的旧助手后手动换用此EXE一次；之后使用应用内更新。

反馈格式
手机型号/系统版本、Windows版本、两端软件版本、操作步骤、预期和实际表现、必要的录屏或错误代码。
请遮挡UID、个人照片和有效配对二维码；不要发送数据库、密钥、登录凭据或整个用户数据目录。
反馈入口：https://github.com/ToStardust/NikkiSync/issues

公测限制
桌面相框及不同厂商实况照片需要继续真机验证。实况参数缺失时不会借用其他照片的数据。在线参数解析默认关闭，需要在电脑设置另行同意后开启。
本软件是《无限暖暖》非官方第三方摄影辅助工具。
