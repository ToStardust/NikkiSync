大喵相机助手 1.0.10 公测版
Windows build 2026102002 / Android code34
日期：2026-10-20

- 修正普通照片 EXIF 的相机重复名称：相机型号 MomoCamera，镜头型号 InfinityNikki，不再重复写入相同的相机厂商。
- 电脑导出、手机保存及关联修图使用一致的字段，镜头厂商继续记录照片所属游戏版本的英文标题。
- 包含 1.0.9 的 LIVE 旋转保存修复，支持低内存、磁盘缓存和不规则尺寸后备处理，保留完整分辨率。
- 手机不支持旋转后的视频编码尺寸时，显示具体原因，可恢复原方向保存。
- 保留自动重连、实时同步、动态预览、分享图、小组件和现有参数关联功能。
- 电脑助手内置与独立下载相同的 1.0.10 APK，可覆盖已有同签名公测版，保留用户数据。

高分辨率 JPEG 封面通过 4K、6K、8K、16K 压力验证；实际 LIVE 视频旋转仍受手机编码器能力限制。不承诺所有机型都能处理同尺寸视频。
LIVE 视频旋转仍会编码视频；封面优先使用压缩系数变换，特殊边缘尺寸可能重编码 JPEG，不会静默缩小尺寸。
