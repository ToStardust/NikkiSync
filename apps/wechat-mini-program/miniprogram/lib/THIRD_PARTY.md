Build adapters explicitly disable implicit RNG and WASM; the caller supplies 64 fresh secure random bytes for the library's static and ephemeral Curve25519 key generation. Missing wx.getRandomValues fails closed. No Math.random fallback, global crypto shim or dynamic code evaluation is used. The adapter checks all-zero DH results. Diagnostic transport remains capped at16 records of4096 plaintext bytes; explicit gallery profile is capped at4096 records with the same per-record size, 16MiB total framed bytes per direction and a ten-minute deadline. Both are far below the upstream cipher's 32-bit counter limit. Application framing and session handling remain our code and require review independently of library quality.

QR contains a one-time random 32-byte PSK. Authentication means possession of the physically scanned QR secret, not independent identification of the Windows device or of a specific human. Anyone who obtains the QR may authenticate. Never log, screenshot/share, put the key in page data/storage/URLs, or upload it in a preview code package. JavaScript cannot guarantee complete erasure of immutable strings or all internal library copies.
